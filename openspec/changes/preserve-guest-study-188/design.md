# Design

Track the active study route when the local Google sign-in begins. Wait for both a successful popup result and the matching observed account before accessing the destination. An unrelated account transition or route change uses the existing privacy cleanup.

Read the validated guest draft before removing it. Full Practice, short Practice and Exam use the existing account-scoped keys. A short Practice manifest retains its question order and run identity. A tab upload transfers only its active local source. Clear URL parameters that force a fresh run or jump so the selected draft wins.

An existing destination draft prompts Keep account draft or Continue guest draft. The safe default keeps the account draft. The dialog discloses that continuing the guest draft replaces the tab-local draft for this session. Writes restore previous target values when a write fails. Guest data remains available after a failed transfer.

Completed review filters are optional draft state. The existing deadline remains absolute. An Exam that began as a guest stays ineligible for History and Notebook batch capture. A transferred public Practice draft can capture future answer events under its new owner. Old responses and checkpoints are never written on sign-in.

## Verification

Verify the storage transfer, declined replacement and failure handling with unit tests. Verify Practice, short Practice, timed and completed Exam, cancellation, repeated auth events and switching accounts in Playwright fixtures. Review the conflict dialog at phone and desktop widths in English and Vietnamese.
