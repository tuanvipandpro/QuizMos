# Design

Keep Resume as the primary action and add a secondary Mock Exam button using the existing Quiz Bank action style. Let the two buttons wrap on narrow screens and keep their mobile hit areas.

Use the existing overview route with the exam mode selected for the latest checkpoint's bank. Setup resolves question eligibility, certification settings and any compatible exam draft. Entering setup does not start or replace a session. An explicit request to replace an active exam uses the existing confirmation dialog.

Continue learning remains based on an available saved checkpoint. The same actions are shown regardless of checkpoint position or Practice completion. The existing bank actions remain available when there is no saved checkpoint.
