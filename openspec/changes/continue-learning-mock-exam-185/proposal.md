# Proposal

## Why

Continue learning only resumes Practice for the latest saved quiz bank. Learners returning to that bank, including those who finished Practice, need a direct path to Mock Exam. Refs #185.

## What Changes

- Add a Mock Exam action to Continue learning alongside Resume.
- Open the same exam setup as the Mock Exam action elsewhere in Quiz Bank.

## Capabilities

### New Capabilities

- `continue-learning-mock-exam`: Direct access to Mock Exam setup from the saved-progress card.

### Modified Capabilities

None.

## Impact

Quiz Bank navigation and responsive actions. The existing checkpoint, exam settings, eligibility and draft contracts apply.
