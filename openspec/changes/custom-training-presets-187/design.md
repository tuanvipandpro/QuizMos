## Setup

Use native selects with visible labels, a 44 px control height and the existing theme tokens. Keep separate certification and training choices while a learner switches formats. Training starts with 50 questions and 60 minutes when the pool supports 50. Count options above the eligible, gradable and nonretired pool are disabled. A smaller positive pool displays a fixed full-pool count and a reason. A pool with zero eligible questions cannot start a new run. Duration is selectable independently for every nonempty pool.

## Session compatibility

Validate the selected settings through the existing session resolver and store them in the current exam draft. Retain the existing numeric contract for explicit older links, including counts and durations outside the new setup menu. Resume restores the saved settings, question order and absolute deadline before evaluating setup choices. Certification format keeps its published range or locked count and answering minutes.

## Verification

Exercise all menu choices and disabled boundaries, nonmatching count and duration, small and empty pools, both feedback modes, elapsed timer, resume with changed choices and the legacy link path. Check labels, sizing and keyboard access in both themes and languages on desktop and touch browsers.
